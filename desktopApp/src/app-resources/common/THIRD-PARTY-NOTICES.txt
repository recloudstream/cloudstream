libmpv (libmpv-2.dll)
---------------------
Plays video. libmpv-2.dll is built from mpv and the libraries it is compiled
with, among them FFmpeg, libass, libplacebo, HarfBuzz, FreeType, dav1d and
zlib. This build includes GPL-licensed parts, so libmpv-2.dll as a whole is
distributed under the GNU General Public License, version 2 or later, which
allows distribution under version 3 (LICENSE.txt).

Build: mpv-dev-x86_64-20261004-git-413ff0b1cd (mpv commit 413ff0b1cd),
built with Clang by the libmpv workflow of
https://github.com/harsh-pockt/cloudstream from the build scripts of
https://github.com/shinchiro/mpv-winbuild-cmake, and published at
https://github.com/harsh-pockt/cloudstream/releases/tag/libmpv-20261004-git-413ff0b1cd

The complete corresponding source code of libmpv-2.dll, with the build
scripts and the exact version of every library in
mpv-dev-x86_64-20261004-git-413ff0b1cd-sources.txt, is published in that
release, which each CloudStream desktop release on GitHub links to.

Source code:
  mpv                 https://github.com/mpv-player/mpv
  Build scripts       https://github.com/shinchiro/mpv-winbuild-cmake
  FFmpeg              https://ffmpeg.org/download.html

Android extension support
-------------------------
Extensions built only for Android are converted for desktop with these
libraries, which are included as they are:

  dex2jar 2.4.38      Apache License 2.0
                      https://github.com/ThexXTURBOXx/dex2jar
                      Includes code from the Android Open Source Project
                      (dx), Apache License 2.0
  ASM 9.10.1          BSD 3-Clause License, https://asm.ow2.io
  Gson 2.14.0         Apache License 2.0, https://github.com/google/gson

The Apache License 2.0 is in LICENSE-Apache-2.0.txt next to this file, and
ASM's licence, which also covers the copy of ASM inside dex2jar, is in
LICENSE-ASM.txt.
